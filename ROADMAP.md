# Roadmap

Possible future work, subject to maintainer and contributor interest:

- Official Instagram API connector for eligible professional accounts
- Gutenberg block in addition to the shortcode
- Optional local media proxy/cache
- Additional layout presets
- Optional text truncation with expandable cards
- Better per-network feed validation and diagnostics
- Automated tests and WordPress coding-standard checks
- Internationalization files and additional translations

The roadmap is not a promise or release schedule. Contributions and design discussions are welcome through issues and pull requests.
